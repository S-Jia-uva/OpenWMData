Contributions to OpenWMData are welcome! All of the code is managed through the [GitHub repository](https://github.com/WilliamNgiam/OpenWMData).

<h2 style="margin: 1em 0em 0.5em 0em">How to submit a dataset</h2>
There are four main ways you can submit a dataset for entry to OpenWMData, which are described in turn below. Note that they are ranked in order of preference, from most preferred to least preferred, by the maintainers of OpenWMData.

<h3 style="margin: 1.33em 0em 0.5em 0em">1. Submit a pull request</h3>
To directly add a dataset yourself, you can open a pull request on Github. First you should fork the OpenWMData library via GitHub and make modifications on your fork. The OpenWMData database is written in <a href="https://www.markdownguide.org/cheat-sheet/" target="_blank">markdown</a> using a standardized, easy-to-copy <a href="https://github.com/WilliamNgiam/OpenWMData/blob/docs/templates/post_template.md" target="_blank">template</a>. To add a dataset, add a markdown file named with the format `{first_authors_last_name.lower()}{year}.md` to the `source/contribute` directory. Once your modification is complete, submit a pull request to merge your changes into the docs branch of OpenWMData. Pull requests will be reviewed by the maintainers.

<h3 style="margin: 1.33em 0em 0.5em 0em">2. Email a completed template file</h3>
Copmlete the provided <a href="https://github.com/WilliamNgiam/OpenWMData/blob/docs/templates/post_template.md" target="_blank">markdown template file</a> for your dataset. Then email the completed file to the <a href="mailto:william.ngiam@adelaide.edu.au">lead maintainer</a>. They will confirm the details in the template and contact you if any clarification is needed. If there are no issues, the lead maintainer will add the dataset to the hub and notify when it is published.

<h3 style="margin: 1.33em 0em 0.5em 0em">3. Fill out a Google form</h3>
Have a dataset to submit? Fill out this form: <a href="https://forms.gle/9So58zJEeM5R1zBc8" target="_blank">https://forms.gle/9So58zJEeM5R1zBc8</a>. This form will be checked periodically, so expect some delays before a response or seeing your dataset being added to the hub.

<h3 style="margin: 1.33em 0em 0.5em 0em">4. Open an issue</h3>
To flag a dataset for entry into the database, you can open a <a href="https://www.github.com/WilliamNgiam/OpenWMData/issues/new" target="_blank">new issue via GitHub</a>. Please provide a link to a repository for the data and, if available, a link to a corresponding manuscript describing the data.
